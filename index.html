Haystack Hustle

A 3D first-person needle-in-a-haystack simulator. Dig through towering voxel haystacks by hand, pitchfork, dynamite and vacuum, sell the hay, upgrade everything, and race to return the hidden needle.

      

        Stats
        

          
24levels, 12 of them hard mode

          
6languages, including Hindi

          
60permanent rebirth upgrades

          
Co-oponline multiplayer rooms

        

      

      

        Under the hood
        
    
          
  • Haystacks are voxel grids drawn with chunked instanced meshes, with frustum culling, so huge stacks stay smooth on low-end laptops.
    • 
          
  • First-person arms use two-bone IK, so the hands really grip each tool.
    • 
          
  • Skeleton raids, 12 collectible talismans, an enchanting anvil and a secret bakery give long-term goals beyond the main loop.
    • 
          
  • Online co-op through Photon, cloud saves through the CrazyGames SDK, and an in-game translation system for 6 languages.
    •

CMS 2018 Co-op

      

    

    
FileEditViewHelp

    

      

      
A multiplayer mod for Car Mechanic Simulator 2018. Invite a friend over Steam and fix cars in the same garage. The game has no multiplayer at all, so everything is synced by hand: the cars, every part, the doors and the lifts.

      

        Stats
        

          
4players per garage

          
4xpart syncs per second

          
3retargeted animations

          
0ports to forward

        

      

      

        Under the hood
        
    
          
  • Loads with BepInEx and hooks the game with Harmony. Networking rides on the Steamworks copy the game already ships, so invites go through Steam.
    • 
          
  • The host's garage is the real one. Cars are streamed with the game's own save code, then only the parts that changed get sent.
    • 
          
  • Guests get their save backed up and restored, and their job system is blocked so it can't edit the host's cars.
    • 
          
  • Other players are a Mixamo mechanic. A Blender script retargets idle, walk and run, paints his texture and bakes it all into one file the mod turns into a skinned mesh at runtime.
    • 
        

      

      

        Built with
        
  • C#
  • BepInEx
  • Harmony
  • Steamworks.NET
  • Blender Python

AnyPS5 contributions

      

    

    
FileEditViewHelp

    

      
AnyPS5 is an open-source tool that ports PS5 executables to Linux and Windows. I've been sending it small fixes found while building it on Windows and digging through its progress map.

      

        #872 · Guard NOMINMAX on Windows merged
        
    
          
  • Four Windows sources redefined NOMINMAX, so every MinGW build printed the same warning four times.
    • 
          
  • Each define now uses the #ifndef guard the rest of the project already uses. The build has no warnings left in project code.
    • 
        

        
View #872

      

      

        #883 · Fix the MemoryPool.hpp include guard merged
        
    
          
  • The header checked ..._LIBKERNEL_... but defined ..._LINKERNEL_..., so its include guard never worked.
    • 
          
  • Found with -Wall -Wextra across all 905 project sources. One-letter fix.
    • 
        

        
View #883

      

      

        #886 · Count sceHttpParseStatusLine as implemented merged
        
    
          
  • The progress map listed this HTTP parser as missing, even though it was written and tested.
    • 
          
  • A range-limit check used the "not implemented" stub, which the progress tool counts as missing. It now throws like its sibling parser, so libraries go from 2449 to 2450.
    • 
        

        
View #886

      

      

        #923 · Correct the barycentric entry in TechnicalDebt merged
        
    
          
  • The known-gaps list said barycentric coordinates were skipped entirely. They're implemented end to end; only GPUs without the barycentric extension fall back.
    • 
          
  • The entry now describes that fallback and links the code behind it. Found while running cppcheck over the whole project.
    • 
        

        
View #923

      

      

        #1115 · Guard NOMINMAX in Rtld.cpp open
        
    
          
  • A file added to the project after #872 brought the same NOMINMAX warning back. Same two-line guard.
    • 
        

        
View #1115

      

      

        #1116 · Read wide strings as 16-bit on Linux open
        
    
          
  • The PS5's wchar_t is 16 bits, but 15 libc string functions used the host's, which is 32 bits on Linux. Wide text got wrong lengths and comparisons, and copies could overrun.
    • 
          
  • Rewrote wcslen, wcscmp, wcscpy, wmemcpy and the rest on 16-bit units, with a new test covering every one of them.
    • 
        

        
View #1116

      

      

        #1126 · Parse wide strings as 16-bit on Linux open
        
    
          
  • Follow-up to #1116: the number parsers (wcstol, wcstod and the rest), wcscoll and wcsxfrm had the same 32-bit problem on Linux.
    • 
          
  • They now parse the ASCII part of the 16-bit string, which is exactly what the C standard allows in the default locale, with tests for every edge case.
    • 
        

        
View #1126

      

      

        How they were tested
        
    
          
  • Built with MinGW-w64 GCC 15.2 on Windows 11 and ran the non-GPU test suite (181 to 196 tests as the project grew), all passing.
    • 
        

      

      

        Built with
        
  • C++20
  • CMake
  • Ninja
  • MinGW-w64 GCC 15
